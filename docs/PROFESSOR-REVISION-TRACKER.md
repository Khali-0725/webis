## Decisions and blockers

- The existing Laravel 13 / React architecture and private file storage remain the basis for the revisions.
- Review of the baseline found that document approval currently verifies a provider after a single document and the admin cannot open that document. These are priority defects.
- The local MySQL server was initially stopped during this run, which made the browser login wait. It was started without changing data; `/api/health` then returned 200 and the live browser checks above passed.
- The prior local database had 12 approved profiles without permits. The user confirmed that all records were test data and authorized a reset. The old database and private uploads were backed up separately; the new demo dataset has 11 approved providers, each with synthetic, visibly invalid ID and permit fixtures. `DatabaseSeeder` refuses to run in production.
