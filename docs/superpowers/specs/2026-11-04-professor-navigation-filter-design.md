# Navigation, filtering, and service results

The professor wants simpler navigation and filtering, with a client search experience that stays inside the portal. The user approved grouped admin navigation, one account profile link through the avatar, no redundant Home entry, a single desktop filter row with 3/5 month presets, and a tabulated Browse Services result that remains usable on phones.

## Navigation

Admin links are grouped by function: Overview; People; Services; Operations; Moderation; System. The current links and routes stay available. Account Profile leaves every sidebar and opens through the top-right avatar. The provider's distinct Business Profile remains. Client Home leaves the sidebar; the WEBIS logo still links home. Search Services opens in the client portal. A client service detail also stays in the portal.

## Filters

The Bookings and Services admin pages shown in the feedback, plus Providers with the same pattern, combine search, their page-specific filter, sort, and date preset into one desktop row. On smaller screens controls stack vertically without horizontal scroll. Last 3 months and Last 5 months set the existing date range fields; Custom dates preserves manual entry. The shared date filter component also offers the presets to other admin record pages.

## Browse Services

Desktop search results use a compact table with service, provider, category, barangay, and price. On phones, the existing responsive table becomes labeled cards. Category, barangay, and price filters remain. Clicking a service preserves the client portal route when the client started there.

## Limits

The unclear “bottom stock” feedback is separate and remains last, as the user requested earlier. Public users keep the public search route and header. No API or database changes are required.
